Inside the code

Real excerpts from each project, with their files and line numbers.

Code-aware chunking

Instead of cutting files into fixed-size windows, the analyst parses each file into an AST and makes one chunk per function, class, method and module, with exact 1-based line ranges, so every answer can cite precise locations.

An index that knows its model

Vectors from different embedding models can't be compared. The saved index records which model built it and refuses to load under a different one, instead of quietly returning wrong matches.

Two threads, one handshake

The C++ client reads the keyboard on the main thread and starts a socket-listener thread only once connected. Login then blocks on a condition variable until the listener sees the server's CONNECTED frame.

Framing a byte stream

TCP delivers bytes, not messages. On the Java server, the decoder takes one byte at a time and emits a complete STOMP frame only when it reaches the NUL terminator, so the same protocol code runs under both the thread-per-client and the Reactor (NIO) server.

A covariance-matched Gaussian twin

One thin SVD of the real ResNet features gives their covariance spectrum and a least-squares teacher. Sampling Gaussians with that exact covariance and signal isolates second-order statistics as the only shared ingredient.

Sweeping model size

Project the features onto the first p columns of a random Gaussian matrix, fit min-norm least squares with the pseudo-inverse, and average over seeded splits. The test error spikes where p equals the number of training samples.

Transfer Learning for Canonical Correlation Analysis

2026 – present · Python · NumPy

CCA finds the directions along which two views of the same data correlate most. With few target samples in high dimension, it overfits. I’m developing a source-free, generic transfer-learning algorithm for CCA, extending prior work on transfer learning for PCA.

  • Implemented CCA from scratch in Python: whitening, SVD, the generalized eigenproblem. Validated against scikit-learn.
  • Baseline sweep: how many USPS target samples target-only CCA needs before it beats reusing MNIST source weights, across ridge strengths.

Double Descent on Real Image Features

2026 · Python · PyTorch · NumPy

Does a regression on pretrained image embeddings show double descent because of the data’s second-order statistics alone? I built a Gaussian twin with the exact covariance and linear signal of real ResNet features and compared their learning curves.

  • Both curves peak at the interpolation threshold, at p = ntrain and n = d, with a bias–variance breakdown.
  • No preprocessing leakage: every split is centered with the training mean only; all runs are seeded.
